# Permissionless Resolution Changer

A mod that connects to Boundless Window and changes the resolution within game.

The mod eliminates the need for macOS permissions to be given.

***THIS IS NOT SPEEDRUN LEGAL YET***

For anyone wondering about the insane amount of versions, it's because I can't build it on my computer.
